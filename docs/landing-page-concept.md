# Landing page concept (parked)

**Status:** Parked. Revisit after the site's visual design, content organization, and UI are further developed. **Do not build from this note yet.**

**Scope:** Sketch only — no UI, components, or code until this note is deliberately un-parked.

---

## Principle

The video hooks the curious; the static layer catches everyone else and gives an immediate next step.

---

## Hero concept

### Motion layer (optional autoplay)

A short looping video (about 15–30 seconds) that shows a letter comparison unfolding:

- Two columns side by side
- Themes lighting up
- A verse anchor sliding in

**Goal:** Sell the “aha” moment before the visitor does anything.

### Static fallback (required)

For users who don’t autoplay (or who skip motion), the hero still works as a static layer:

- **Headline (one-line promise), e.g.**  
  “Thirteen letters. Thirty-six cities. Every road Paul walked.”
- Clear visual that still implies comparison / map / journey without requiring the video

---

## Entry points

Three or four tappable cards below the hero, each leading into a different part of the experience. Examples:

1. **Start with a comparison** → compare / letter pairs
2. **Explore the cities** → city context packs / map
3. **Follow the timeline** → biographical timeline
4. *(Optional fourth)* e.g. **Browse interpretive themes** → cultural / themes index

Exact labels and destinations can be tuned once IA and routes are stable.

---

## Anti-pattern to avoid

**Do not** use a full tutorial video as the first-visit experience. That asks for too much commitment before visitors feel value.

**Instead:** let the interactive thing be the tutorial.

- First visit gets a gentle nudge such as **“Try Romans and Galatians”**
- That pair is pre-loaded so they land *inside* the experience rather than watching an explanation

---

## How the layers work together

| Layer | Role |
| --- | --- |
| Short loop video | Hook the curious with the comparison “aha” |
| Static hero + headline | Catch everyone else; name the promise in one line |
| Entry cards | Immediate next step into comparison, cities, timeline (and optional themes) |
| Soft first-visit nudge | Pre-load a strong starter pair; teach by doing |
